helm release

v0.1.1 Polish Update

This release tightens the public product surface around updates, activation, and launch flow while keeping the core Windows + WSL approval experience intact.

English highlights

  • Approval flow for Claude Code, Codex, and Gemini CLI
  • GUI handling for AskUserQuestion
  • Smarter low-risk auto-approve and danger-priority queueing
  • Clearer purchase, license activation, and update messaging
  • Faster first-switch behavior for Home, History, and Settings

中文重点

  • 支持 Claude Code、Codex、Gemini CLI 的审批链路
  • 支持 AskUserQuestion 的 GUI 回答
  • 低风险读取可自动放行，危险请求优先排队
  • 购买、激活、更新相关文案统一收口为产品表达
  • 主页、历史、设置的首次切换冷路径进一步提速

System requirements

  • Windows 10 or 11
  • WSL2
  • WebView2 runtime
  • Claude Code, Codex, or Gemini CLI installed inside Linux

系统要求

  • Windows 10 / 11
  • WSL2
  • WebView2 runtime
  • Linux 环境内已安装 Claude Code、Codex 或 Gemini CLI

Known gaps

  • Gemini CLI still needs broader real-world validation.
  • Some final UI and motion polish is still ongoing.
  • Long-running Windows session validation still benefits from more field time.
